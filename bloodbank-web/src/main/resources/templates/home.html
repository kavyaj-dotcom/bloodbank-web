How It Works

A simple workflow to support blood request processing and donor discovery.

1

Check Blood Availability

The system checks the inventory for the requested blood group.

2

Find Potential Donors

If stock is unavailable, the system searches for potential donors using ABO/Rh compatibility and recorded location information.

3

Send SMS Notifications

Matched donors are notified about the emergency blood request by SMS.
